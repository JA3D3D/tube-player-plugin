BUILD TUBE PLAYER ON GITHUB (no software to install)

GitHub's free Mac computers compile the plugin for you. About 15 minutes.

1. On github.com, make a new repository called tube-player-plugin
   (Public = unlimited free builds). Don't add a README.
2. On the empty repository's page, click "uploading an existing file".
   Drag in everything from this folder EXCEPT this text file, and press
   "Commit changes".
3. Click the "Actions" tab.
   - If you see "Build Tube Player" running, skip to step 4.
   - If not (Mac hides the .github folder, so it may not have uploaded):
     click "set up a workflow yourself", delete what's in the editor,
     paste in everything from build-workflow.yml, and press
     "Commit changes". The build starts by itself.
4. Wait for the green tick (about 15 minutes). Click the finished run,
   scroll to "Artifacts" and download "Tube-Player-mac".
5. Unzip it, then unzip "Tube Player for Mac.zip" inside, and double-click
   "Install Tube Player.command" (see README.txt in that folder).
